# Submission paper (LaTeX)

The Phase 1 submission paper in IEEE conference format (`IEEEtran`, A4). Every number traces to
`docs/CLAIMS_LEDGER.md`: `python -m shahid.check_numbers` checks the text of every section and
`python -m shahid.check_tables` requires every table number verbatim in `docs/RESULTS.md`, the ledger
or a study README.

## Build

Needs [Tectonic](https://tectonic-typesetting.github.io) (XeTeX; downloads the LaTeX packages and
fonts it needs on first use) and, for clean PDF metadata, `pypdf` from `requirements-dev.txt`. From
the repository root:

```
python -m shahid.build_proposal --draft    # placeholders printed in red
python -m shahid.build_proposal --final    # stops and lists every unfilled placeholder
```

The build writes `SHAHID_Phase1_Proposal.pdf` at the repository root. The author line and the
repository URL are set once, at the top of `main.tex` (`\authorline`, `\repourl`).

## Layout

| Path | Content |
|---|---|
| `main.tex` | preamble, fonts, submission settings, the `\teamtodo{...}` placeholder macro |
| `sections/` | one file per paper section, `00_abstract.tex` to `14_appendix.tex` |
| `references.bib` | verified references only (`docs/literature/REFERENCES.md` and sources fetched for the business case) |
| `figures/` | data figures, generated by `python -m shahid.proposal_figures`; never edited by hand |
| `design/` | TikZ design figures: the pipeline is used by the paper; the operator-screen mock-up and the hardware bench belong to the earlier proposal (`docs/PRELIMINARY_DESIGN.md`) |

Figures contain information from the SimBench database, made available under the ODbL 1.0.
